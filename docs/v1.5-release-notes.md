# PEMDS v1.5 — Release Notes

**Date:** 2026-10-09
**Code version:** 1.5.0
**Base:** v1.0.0 (see `v1.0-release-notes.md`)

v1.5 is a focused usability release driven by field feedback. It narrows the
GUI to the pressure-containing workflow (vessel, piping, flange, storage tank),
simplifies vessel inputs, and turns the storage tank into a plate/course
take-off tool.

## Changes

### Pressure vessel (PV)
- **Test temperature removed.** The `test_temperature_c` input and the test-case
  temperature coupling are gone. Hydrostatic test pressure is now the
  conservative `P_T = 1.3 · MAWP` (the `UG-99(b)` form with `S_T = S`).
- **Straight-nozzle-only schedule.** The nozzle editor now captures straight
  nozzles only: tag, outside diameter, neck thickness, projection, elevation and
  service. Azimuth (circumferential position) is no longer a data-entry field; it
  keeps its model default of 0° and is still used by the 3D preview and drawing.

### Flange / nozzle (FL)
- **Gasket type** is now a dropdown: `spiral-wound`, `sheet`, `ring-joint`.
- **Facing** is now a dropdown: `raised_face`, `flat_face`, `ring_joint`.
  Both are closed enums, so invalid values are rejected at the input boundary.

### Storage tank (TK, API 650 — experimental)
- **Roof calculation is optional** (`include_roof_calculation`, on by default).
  Untick it to report shell plates and openings only.
- **Plate / course layout.** New inputs `plate_width_mm` (one course height) and
  `plate_length_mm` (circumference segment). The pack now:
  - sizes the shell **course by course** with the one-foot method at each course's
    design point, so the **bottom course is thickest and the top thinnest**;
  - reports, per course, the required thickness plus the **maximum liquid level
    and static pressure that course can sustain** for the supplied plate;
  - computes **number of courses** = `ceil(H / plate_width)` and **plates per
    course** = `ceil(π·D / plate_length)`, and the **total plate count**;
  - reports the **zig-zag stagger offset** (half a plate length) so vertical
    joints alternate between successive courses.

### Material database
- **Added 12 selectable materials**, available to every equipment that chooses a
  material (vessel, piping, storage tank, and the CLI packs):
  - IS pressure-vessel plate grades: `IS 2002:1962` Gr. 1 / 2A / 2B,
    `IS 2041:1962` Gr. 20 Mo 55 and 20 Mn 2, `IS 1570:1961` Gr. 15 Cr 90 Mo 55
    and Gr. C 15 Mn 75.
  - Generic categories: hot rolled carbon steel, 5% Cr Mo, 11.8% Cr Ni,
    13% Cr Ni, 18 Cr 2 Ni steel.
  - These carry **demonstration allowable-stress mappings** to equivalent ASME
    materials and are flagged `UNVERIFIED` in the provenance header; results
    backed by them remain labelled *experimental* (VAL-2).

### GUI scope
- **Heat exchanger, column/reactor and pump are removed from the GUI family
  selector.** Their packs still exist and remain reachable from the CLI/API
  (still experimental); the desktop tool now presents vessel, piping, flange and
  storage tank only.

## Exit status

- Tests: the full suite passes; new tests cover course-wise thinning, plate
  counts, the optional roof, and the GUI scope change.
- Gates: `ruff`, `mypy` and `scripts/citation_lint.py` are clean.
- **Human gates unchanged from v1.0:** legal review (R-2) and licensed-edition
  transcription of the demonstration data tables (results backed by `UNVERIFIED`
  data remain labelled *experimental*).
