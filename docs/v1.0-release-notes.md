## Honest data-status note

Allowable-stress, B16.5 rating/bolting/gasket, and pump sample-curve data are
**demonstration values marked `UNVERIFIED`** in their provenance headers,
pending transcription from licensed editions. Per the data policy and VAL-2,
any result backed by them is surfaced as **EXPERIMENTAL** with a warning —
including FL and PU selection results — so a "verified pack" label is only
earned once the backing tables are reviewed and the `checked_by` fields updated.

## Pending human gates before production release

1. **Legal review** (R-2): confirm the CIT/data posture with counsel before release.
2. **Data transcription**: replace UNVERIFIED demonstration tables from licensed
   editions and review each row (`checked_by`).
3. **Third-party validation** (VAL-5) is staged for v2.0 per the roadmap.

## Out of scope (unchanged from spec §12)

regulatory filing. Deferred [S]/[C] items remain staged for v1.1+.
